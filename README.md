# Electrician theory training

Interactive revision notes and flashcards for UK electrical theory, written while training as an electrician. The lessons explain each idea in plain English, with diagrams you can play with and a quiz at the end.

**Live site:** https://paul-norman.github.io/electrician-theory-training/

## What's here

- `revision/`: the revision course, grouped by topic (electrical principles, cables, supply and distribution)
- `revision/review/`: typed-answer flashcards with spaced repetition. Progress is saved in your own browser only.
- `earth-fault-loop.html`: an interactive earth fault loop explorer

Plain HTML, CSS and JavaScript: no build step and no dependencies beyond Google Fonts. Open `index.html` through any web server to run it locally.

## A note on accuracy

These are revision aids, checked against standard UK references, but they're not a substitute for BS 7671, the On-Site Guide or your course materials. If something looks wrong, please open an issue.
